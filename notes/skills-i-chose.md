# Skills Research Notes — Email Marketing Studio

## Use these

**1. anthropics/knowledge-work-plugins — for campaign planning and email sequences**
Publisher: Anthropic (official). GitHub stars: **34,416**.
Relevant skills: `campaign-plan` (3.3K installs) and `email-sequence` (3K installs).
Why trust it: This is Anthropic's official repository of first-party knowledge-work tools. While the install counts are lower than some community alternatives, this comes directly from the company that built Claude Code. Official publishers have their reputation on the line and maintain their tools. The high GitHub star count (34K+) confirms this is a widely-reviewed, trusted repository.

**2. resend/resend-skills — for actually sending email**
Publisher: Resend (official email API company). GitHub stars: 208 on resend-skills, but **19,900 stars** on resend/react-email (same organization).
Relevant skills: `resend` (24K installs), `resend-cli` (13.7K installs), `react-email` (9.8K installs).
Why trust it: Resend publishes skills for their own email API. You're getting tools written by the people who built the service, not a third-party interpretation. The 20K stars on their react-email repo confirms the organization is legitimate and actively maintained. When you need to connect to a service, always prefer the official publisher's skills over community alternatives.

---

## Avoid these

**1. open.feishu.cn@lark-mail — despite having 837K installs (highest in all searches)**
This is Lark/Feishu, ByteDance's enterprise collaboration platform. The massive install count is misleading — those are Lark enterprise users, not email marketers. Lark is an internal messaging system like Slack, not an email marketing tool. This teaches an important lesson: install count without context is meaningless. High popularity in the wrong use case is worse than low popularity in the right one.

**2. caffeinelabs/skills@extension-email-marketing — 29.4K installs, but only 2 GitHub stars**
The username "caffeinelabs" has no verifiable identity or reputation. With only **2 GitHub stars** but 29K installs, there's a massive mismatch. Stars are harder to fake than install counts and represent actual developer review. For a skill that will guide how you write to real customers, you need to know who wrote it and trust their judgment. No accountability means no recourse if the advice is wrong or the skill gets abandoned.

## How I decided

These are the three things I check before installing any skill:

1. **Is the publisher official or well-known?** Skills from the company's own GitHub account (anthropics/knowledge-work-plugins, resend/resend-skills) are safer than random usernames. Official publishers stake their company reputation on quality. Community publishers can disappear overnight.

2. **How many GitHub stars does the repository have?** Stars represent independent developer review and are harder to game than install counts. A repo with 30K+ stars (like anthropics) or associated repos with 20K+ stars (resend/react-email) shows sustained community trust. Compare: caffeinelabs has 29K installs but only 2 stars — clear red flag.

3. **Does the skill actually match my use case?** Read descriptions carefully. The highest install count in my entire search (837K for lark-mail) is completely wrong for email marketing — it's for internal enterprise messaging. Relevance beats popularity every time. Don't install something just because it has high numbers.

**Bonus check:** For established publishers, look at their other repositories. Resend's skills repo has only 208 stars, but their react-email repo has 19,900 stars, proving the organization is real and trusted.
