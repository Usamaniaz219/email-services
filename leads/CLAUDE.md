# Leads Folder Rules

## Practice Data Only

- All contacts in this folder are **made-up practice people**
- Never add real people or real email addresses
- Every email must end in **@example.com** (a reserved domain that cannot receive mail)

## Data Requirements

- Every row must have a `consent` value indicating how they opted in
- Never change existing @example.com addresses
- Maintain data integrity: all required columns must be filled

## Why These Rules Exist

This is a practice environment for learning email marketing. Using @example.com ensures we can never accidentally email real people while we learn and experiment.
